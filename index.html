Privacy Policy - Jarvis-AI

Last updated: August 2026

Jarvis-AI ("the App") is a personal automation assistant that connects to Instagram Direct Messages to provide automated replies on behalf of its owner.

What information we collect

When someone sends a Direct Message to the connected Instagram account, the App receives the message text and the sender's Instagram user ID through Instagram's Messaging API, in order to generate a relevant automated reply.

How we use this information

Message content is temporarily processed to generate a reply using a third-party AI language model (Groq). A short rolling history of recent messages per conversation may be kept in memory to provide more relevant, context-aware replies. This data is not sold, shared with advertisers, or used for any purpose other than generating replies.

Data storage

Conversation history is stored temporarily in memory on the App's server and is not permanently retained. No message data is shared with any third party other than the AI provider (Groq) used solely to generate the reply text.

Data retention

Message data is not permanently stored. Temporary in-memory history is cleared when the server restarts.

Third-party services

This App uses the Meta Instagram Graph API to send and receive messages, and the Groq API to generate AI-based responses. Each of these providers has its own privacy policy governing their handling of data.

Contact

For questions about this privacy policy or how your data is handled, please contact the app owner directly through Instagram.

This privacy policy applies solely to the Jarvis-AI Instagram messaging automation app.
